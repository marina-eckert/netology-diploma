# Бесплатное размещение

Приложение рассчитано на один Docker-сервис Render Free и PostgreSQL Neon Free.
Тарифы имеют ограничения: Render останавливает сервер после простоя, первое открытие может занять около минуты. При перезапуске потребуется войти заново.

1. Создайте проект PostgreSQL в Neon на бесплатном тарифе. Сохраните строку подключения с `sslmode=require`.
2. Отправьте актуальные исходники в GitHub.
3. В Render создайте Blueprint из репозитория: настройки находятся в `render.yaml`. Проверьте тариф **Free**.
4. Укажите строку Neon в секретной переменной `DATABASE_URL`.
5. Дождитесь успешной сборки и откройте адрес HTTPS, выданный Render.

`SESSION_SECRET` и `DEMO_PASSWORD` создаются автоматически. Пароль демонстрационных аккаунтов смотрите в переменных окружения Render; локальный пароль из README здесь не используется. При первом запуске создаются таблицы, книги и аккаунты. Изменение `DEMO_PASSWORD` после этого не меняет пароли существующих пользователей.

`UPLOAD_STORAGE=database` сохраняет загруженные обложки в PostgreSQL, поскольку файловая система Render Free временная. Локальный Docker по умолчанию хранит обложки в томе uploads. Ограничение одного файла — 5 МБ. Следите за свободным местом в Neon.

Проверка доступности `/api/health` не выполняет запросов к PostgreSQL и позволяет базе засыпать. Не добавляйте платные диски и Render PostgreSQL: бесплатная база Render имеет ограниченный срок действия.

После размещения проверьте регистрацию, вход, бронирование, сообщения поддержки и загрузку обложки. Передайте проверяющему ссылку на приложение и нужные демонстрационные учётные данные отдельно.
